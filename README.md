# TripPocket

Личный кошелёк на телефоне: единый журнал расходов и доходов с разбивкой по
сферам жизни (Повседневные · Крупные · Квартира · Путешествия), месячным
дашбордом и полноценным трекером трат в поездках с мультивалютностью.
Работает офлайн, данные хранятся локально на телефоне в SQLite.

Вырос из трекера трат в путешествиях и заменил собой эксельку Fin_tracker —
вся её история (с мая 2025) импортируется, см. «Импорт истории» ниже.

> Технологии: React Native (Expo) · expo-router · expo-sqlite · TypeScript ·
> i18n (RU/EN) · gifted-charts. Архитектура — в `CLAUDE.md`.

## Возможности

- ✍️ **Быстрая запись** расхода или дохода: сумма (с калькулятором), сфера,
  категория — 2–3 тапа; шаблоны частых трат
- 🗂 **Сферы** со своими категориями и лимитами (месячный и дневной, с
  предупреждением о превышении)
- 📓 **Журнал**: все записи по месяцам, фильтры по типу/сфере, поиск, правка
- 📊 **Обзор месяца**: расходы/доходы/дельта/% накоплений, по сферам с
  лимитами, категории (пончик), дни недели, история по месяцам
- 🧳 **Поездки**: бюджет в своей валюте, остаток, прогноз до конца, «сколько
  можно тратить в день»; трата «в поездке» одновременно живёт и в общем
  кошельке (в рублях), и в бюджете поездки (в её валюте)
- 💱 **Мультивалютность**: авто-курсы с кэшем для офлайна + **свои курсы**
  («отдал 105 000 ₽ — получил 1 000 €») — пересчёт идёт по реальной цене
  покупки валюты
- 🌐 RU/EN, светлая/тёмная тема
- 📤 **Экспорт**: JSON-бэкап v2 (восстановление + внешняя аналитика) и CSV

## Запуск на iPhone (через Expo Go)

Рабочий цикл — обновления по воздуху через EAS Update, дев-сервер не нужен:

```bash
npx eas-cli update --branch preview --message "что поменялось"
```

После публикации: открыть проект в Expo Go заново (иногда нужен второй заход).
Номер сборки виден внизу Настроек — он бампается в `app/(tabs)/settings.tsx`.

Локальная разработка по старинке:

```bash
npm install        # один раз
npx expo start     # QR-код → камера iPhone (одна Wi-Fi сеть)
```

## Импорт истории из эксельки

Импорт **заменяет** все данные приложения содержимым файла, поэтому два случая.

**В приложении нет своих записей** (или их не жалко):

```bash
python3 scripts/fin_tracker_to_backup.py "~/Downloads/Fin_tracker (1).xlsx" -o trippocket-import.json
# → JSON на iPhone (AirDrop → Файлы) → Настройки → Импорт из бэкапа
```

**В приложении уже есть записи, которые надо сохранить:**

```bash
# 1. iPhone: Настройки → Экспорт данных (JSON) → AirDrop на Mac
# 2. Слить ексельку с данными приложения:
python3 scripts/fin_tracker_to_backup.py "~/Downloads/Fin_tracker (1).xlsx" \
    --app-backup ~/Downloads/trippocket-backup-ГГГГ-ММ-ДД.json \
    -o trippocket-import.json
# 3. JSON на iPhone → Настройки → Импорт
```

Дубликатов не будет: у записей эксельки детерминированные id по номерам строк,
экселька при слиянии — источник правды, из бэкапа приложения доливается только
то, чего в ней нет (записи из приложения, поездки, ручные курсы). Поэтому
правило: **дописывай строки в конец листов**, не вставляй в середину и не
удаляй старые. Дозаполнил ексельку → перегнал той же командой → импортировал.

Готовый файл в корне проекта: `trippocket-import.json` (884 расхода + 94 дохода
+ 40 категорий по май 2026, сверено с дашбордом эксельки).

## Аналитика на компьютере

Работает на том же JSON (экспорт из приложения или `trippocket-import.json`):

```bash
python3 scripts/analyze.py trippocket-import.json      # текстовый отчёт в терминал
jupyter lab scripts/analytics.ipynb                    # ноутбук с графиками
```

Отчёт: сводка и помесячная таблица по сферам с % накоплений, категории
повседневных, дни недели, контроль лимита, тренды категорий месяц-к-месяцу,
дни-выбросы, прогноз месяца. В ноутбуке то же в виде графиков + теплокарта
«категория × месяц».

## Где хранятся данные

Локально на устройстве в SQLite (`trippocket.db`). Схема развивается через
миграции (`PRAGMA user_version`) — обновление кода данные не теряет. Для
переустановки/смены телефона — экспорт JSON (Настройки → Экспорт данных).

## Структура проекта

```
app/                    экраны (expo-router)
  (tabs)/               табы: добавить · журнал · обзор · поездки · настройки
  transaction/[id].tsx  правка записи (модалка)
  trip/                 создание/правка поездки
  categories.tsx        категории по сферам (модалка)
  templates.tsx         шаблоны частых трат
  rates.tsx             свои курсы валют («отдал/получил»)
  converter.tsx         калькулятор валют
src/
  db/                   SQLite, миграции, типы
  repositories/         слой доступа к данным (без SQL в экранах)
  services/             валюты, аналитика, экспорт/импорт
  hooks/                загрузка данных
  components/           переиспользуемый UI
  i18n/                 переводы RU/EN
  lib/                  валюты, даты, калькулятор, id
  theme/                дизайн-токены
scripts/
  fin_tracker_to_backup.py   конвертер эксельки → JSON-бэкап v2
  analyze.py                 текстовый отчёт по выгрузке (stdlib, без зависимостей)
  analytics.ipynb            ноутбук с графиками (pandas + matplotlib)
trippocket-import.json       готовый бэкап с историей из эксельки
```
